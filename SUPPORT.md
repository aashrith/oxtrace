# Getting help

* **Questions, ideas, "is this possible?":** start a thread in
  [GitHub Discussions](https://github.com/aashrith/oxtrace/discussions).
* **Something is broken:** open a [bug report](https://github.com/aashrith/oxtrace/issues/new/choose).
  Please include `uname -r`, distro, architecture and OpenSSL version.
* **Security issues:** report privately; see [SECURITY.md](SECURITY.md).

oxtrace is maintained by volunteers. Responses are best-effort, usually within a week.

For general eBPF and Aya questions, the [Aya Discord](https://discord.gg/xHW2cb2N6G) and the
[eBPF Slack](https://ebpf.io/slack) are great communities.
